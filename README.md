# Đức Nguyễn — Personal Portfolio

A responsive starter portfolio built from scratch with semantic HTML, CSS, and a small amount of JavaScript.

## Run locally
1. Extract the ZIP.
2. Open the `duc-nguyen-portfolio` folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## Customize before publishing
- Replace the sample project cards with your real projects.
- Update the GitHub and LinkedIn links in `index.html`.
- Replace `your.email@example.com` with your real contact email.
- Edit the introduction and skills to accurately reflect your experience.

## Validate
Open https://validator.w3.org/ and validate `index.html` by direct input or file upload. Fix any issues shown by the validator before submitting screenshots.

## Test responsive behavior
Open the page in Chrome, press F12, and click the device toolbar icon. Test at mobile, tablet, and desktop widths.

## Publish with GitHub Pages
1. Create a GitHub repository and upload `index.html`, `style.css`, and `script.js` to its root.
2. Open repository Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select `main` and `/ (root)`, then save.
5. Wait for the published URL to appear in the Pages section.
